# open-search-results Extension for VS Code

"open-search-results" is a powerful Visual Studio Code extension designed to enhance your productivity with intelligent paste operations, allowing for seamless integration and formatting of copied content.

## Features

- **Intelligent Code Formatting:** Automatically formats pasted code snippets according to the active language and style guide.
- **Smart Text Adjustments:** Adjusts pasted text to match the surrounding content seamlessly, minimizing manual formatting effort.
- **Multilingual Support:** Works with multiple programming languages for versatile integration.

> Tip: Use animations to showcase how "open-search-results" improves your workflow efficiently!

## Requirements

- Visual Studio Code version 1.60.0 or higher.
- Node.js version 14.x or higher for development purposes.

## Extension Settings

The "open-search-results" extension provides the following settings:

- `smartPaste.enable`: Enable or disable the open-search-results extension.
- `smartPaste.autoFormat`: Automatically format pasted content when enabled.
- `smartPaste.languageSupport`: Specify language support configurations if needed.

## Known Issues

- Inconsistent formatting may occur with non-standard language settings. Please ensure your language settings are standard.
- Some formatting features may not work with third-party extensions that override default paste behavior.
